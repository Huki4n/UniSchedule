# Расписание

Доску собирает `ViewModels/ScheduleComposer`. Номер недели и чётность считает `Services/AcademicCalendar`. «Ближайшая» и подсветка сегодняшнего дня берут `DateTime.Now`. Колонки берут просматриваемую дату из `MainWindow.ReloadSchedule`.

## Неделя семестра

`GetWeekNumber(date, semesterStart)`: разница дат в днях. Если дата раньше начала семестра, номер равен 1. Иначе `дни / 7 + 1`. Неделя 1 нечётная (`WeekParity.Odd = 1`), чётные номера — `Even = 2`, «все недели» — `All = 0`.

Подпись шапки: `Неделя N · нечётная|чётная`.

`AppliesThisWeek`: неделя внутри `[WeekFrom, WeekTo]`, если границы заданы, и совпадает чётность. Открытая граница с одной стороны не режет другую. `AppliesOnDate` дополнительно требует тот же день недели.

Карточка, которая не действует в дату своей колонки, остаётся на доске и помечается `IsDimmed`. В «Ближайшую» такая пара не попадает.

Две карточки одного дня помечаются `IsOverlap`, если обе действуют в дату колонки и их интервалы пересекаются: начало одной раньше конца другой. Касание встык, `10:00` и `10:00`, пересечением не считается. Приглушённая пара в пересечение не входит. Подсветка «К неделе» рисуется поверх этой рамки.

## Доска

Колонки только пн–сб выбранной календарной недели. Понедельник недели считает `AcademicCalendar.StartOfWeek`. Заголовок колонки — `ColumnTitle`: «Понедельник, 5 окт.». `IsToday` — дата колонки совпадает с сегодня, а не только день недели. Воскресной колонки нет. Пара, созданная в воскресенье, записывается на понедельник — см. [interaction.md](interaction.md).

Карточки с одним временем начала стоят в одном ряду по всем дням, если доска шире 980. День без пары на это время оставляет ячейку пустой: карточки ниже не поднимаются. Несколько пар с одним началом в одном дне стоят стопкой в этой ячейке. Ряды собирает `ScheduleComposer` в `Rows`: первая строка — заголовки дней, дальше по одному ряду на каждое начало. Если доска уже 980, дни идут столбиком: у каждого свой заголовок и карточки сверху вниз. Время между днями в этом виде не выравнивается.

`ScheduleComposer.Build` принимает просматриваемую дату отдельно от «сейчас». Если её нет, берётся «сейчас». Подпись «Неделя N» считается от просматриваемой даты. `IsDimmed` смотрит на дату колонки: календарная неделя может задеть две недели семестра, и понедельник с пятницей тогда приглушаются по-разному. Строка «Ближайшая» всегда считается от «сейчас», листание недели её не меняет.

Поиск обрезается по краям. Пустой запрос показывает все пары группы. Иначе остаются пары, у которых предмет, преподаватель, аудитория или заметки содержат запрос без учёта регистра. Тип занятия в поиск не входит.

Если после фильтра пар нет, `NextLessonLabel` получает `ScheduleComposer.EmptyScheduleText`: «Пар нет. Добавьте вручную или выберите группу из импортированного файла.» Колонка без карточек показывает по центру `ScheduleComposer.EmptyDayText`: «Пар нет».

## Карточка

`LessonCardVm`:

| Поле | Откуда |
| --- | --- |
| `TimeText` | `чч:мм–чч:мм` |
| `StartText`, `EndText` | начало и конец первой строкой карточки: `чч:мм–чч:мм`. Предмет и остальные строки идут под временем |
| `Subject` | предмет под временем |
| `Place` | аудитория, иначе «Онлайн» при непустом `MeetingUrl` |
| `Meta` | преподаватель, чётность (если не все недели), диапазон недель. Тип сюда не пишется: его показывает цветная полоска |
| `Detail` | `Meta` и аудитория одной строкой под предметом. «Онлайн» и пустое место в строку не входят. Пустая строка не занимает место |
| `Notes` | заметки одной строкой: переносы схлопываются в пробел. Пустые не занимают место, длинные обрезаются |
| `Badge` | «онлайн», если `MeetingUrl` — ссылка звонка и место уже не «Онлайн» |
| `ShowOnline` | плашка «Онлайн», если `Place` — «Онлайн» или `Badge` не пуст. Отдельной строки «Онлайн» нет |
| `IsOnline` | есть `MeetingUrl` или `LmsUrl` |
| `IsCurrent` | пара идёт сейчас: дата колонки — сегодня, карточка не приглушена, `начало ≤ сейчас < конец`. Из нескольких берётся та, что началась позже. Рамка как у «К неделе» |
| `Accent` | `LessonAccent.For`: практика `#34D399`, лабораторная `#FB923C`, зачет `#FBBF24`, экзамен `#F87171`. Для остальных типов ссылка звонка даёт `#A78BFA`, иначе `#60A5FA` |
| `HomeworkLinks` | строки «ДЗ» на дату колонки. См. [homework.md](homework.md) |
| `IsOverlap` | у пары рамка `AppWarning` и подпись «пересечение» |

Подписи типов: Лекция, Практика, Лабораторная, Зачет, Экзамен. На карточке их нет, цвет — `Accent`. Диапазон недель: `с–по нед.`; пустая граница заменяется на 1 или на `WeekFrom`. Ссылка занятия на карточке — строка «Ссылка на занятие», ссылка LMS — «Ссылка на LMS». Одинаковый адрес без учёта регистра показывается один раз, подписью «Ссылка на занятие». Клик по строке открывает этот адрес и не открывает пару.

## Ближайшая пара

`BuildNextLessonText` смотрит семь календарных дней от сегодня, воскресенье пропускает. Если сегодня пара уже началась и ещё не кончилась (`начало ≤ сейчас < конец`) и `AppliesOnDate`, строка — `Сейчас: предмет · до чч:мм · место`. Из нескольких идущих берётся та, что началась позже. Иначе берётся первая пара, у которой `AppliesOnDate`, и для сегодняшнего дня начало ещё впереди. Завтра и дальше время начала не сравнивается с текущими часами.

Текст ближайшей: `Ближайшая: предмет · сегодня|завтра|<день> чч:мм–чч:мм · место`. Если за неделю ничего нет — `Ближайших пар на неделю нет`. Клик по строке «Сейчас» или «Ближайшая» открывает эту пару. Пустое расписание и «Ближайших пар на неделю нет» кликом не открываются. `CurrentLesson` — идущая пара, иначе `null`. `OpenLesson` — пара этой строки, иначе `null`. Раз в минуту окно заново считает строку, рамку `IsCurrent` и подсветку сегодняшнего столбца по `DateTime.Now`. Колонки, прокрутка и открытая панель при этом не трогаются.

Поиск фильтрует и эту строку: в кандидаты попадают только видимые пары.

## Дисциплина по выбору

Ячейка с несколькими преподавателями после «по выбору» пишется несколькими парами с одним `ElectiveKey`. Разбор — в [loading.md](loading.md). На доске, в «Ближайшей» и в напоминании о паре видна одна из них. Без записи в `ElectivePick` это первая в порядке импорта. Запись хранит группу, день, начало `hh:mm` и предмет. Повторный импорт выбор не стирает: если предмет снова есть в этом слоте, показывается он.

Под строкой группы и поиска `ElectiveHost`: подпись «Курс по выбору» и кнопка `ElectiveBox`. В выпадающей панели один чекбокс на предмет, без дня и времени. Клик по строке только меняет галочку, панель остаётся открытой. Закрытый вид показывает отмеченные названия. Пока пользователь сам не отметил галочки, на доске по-прежнему один вариант слота: запись `ElectivePick` или первый предмет. После первой галочки набор пишется в `ElectiveSubject` и дальше доска показывает все отмеченные предметы во всех слотах, где они есть. Сняты все — этих пар на доске нет. Поиск по неотмеченному предмету показывает его на доске и галочку не ставит; пустой поиск снова берёт набор. Напоминание о домашке скрытого варианта не глушится.

Сохранение пары с `ElectiveKey` обновляет `ElectivePick` этого слота. Если для группы уже есть набор `ElectiveSubject` и в нём отмечен прежний предмет, имя в наборе меняется на новое: курс остаётся выбранным. То же для соседей серии, которым скопировали новое название. Если после сохранения другая elective-пара группы всё ещё носит старое имя, старое имя в наборе остаётся, а новое добавляется.

Сетка месяца — в [homework.md](homework.md).

## Одно название

Пары одной группы с одинаковым предметом, без учёта регистра, считает связанными `LessonSeries`. День и время у каждой свои. При сохранении существующей пары, если такие есть, после кнопки «Сохранить» спрашивается область: только эта, эта и следующие, все с этим названием. Отмена вопроса не закрывает панель пары. «Следующие» — более поздний день недели, а в тот же день более позднее начало. На выбранные пары копируются предмет, тип, преподаватель, кабинет, обе ссылки, заметки, чётность и диапазон недель. День, начало, конец и `Source` не копируются. Список соседей для области берётся из `GetLessons` в момент сохранения, а не из снимка при открытии панели: пара, удалённая с доски пока панель была открыта, в серию не входит. Эта пара и выбранные соседи пишутся одним `UpsertLessons`: одна транзакция SQLite.

Если название изменилось, первое название этого календарного дня пишется в `SubjectRollback`. Повторная смена в тот же день его не затирает. Кнопка у поля «Предмет» подставляет его обратно. Сохранение этого названия удаляет запись. На следующий день записи нет: чужие даты стираются при чтении и при новой записи. Удаление пары и повторный импорт уносят запись вместе с парой. Запомнить, забыть или ничего не делать решает `SubjectRollbackPolicy` по предыдущему названию, уже записанному на сегодня и новому. Окно только вызывает методы базы.
