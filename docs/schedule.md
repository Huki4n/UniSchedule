# Расписание

Доску собирает `ViewModels/ScheduleComposer`. Номер недели и чётность считает `Services/AcademicCalendar`. Оба вызываются с одной датой «сейчас» из `MainWindow.ReloadSchedule`.

## Неделя семестра

`GetWeekNumber(date, semesterStart)`: разница дат в днях. Если дата раньше начала семестра, номер равен 1. Иначе `дни / 7 + 1`. Неделя 1 нечётная (`WeekParity.Odd = 1`), чётные номера — `Even = 2`, «все недели» — `All = 0`.

Подпись шапки: `Неделя N · нечётная|чётная`.

`AppliesThisWeek`: неделя внутри `[WeekFrom, WeekTo]`, если границы заданы, и совпадает чётность. Открытая граница с одной стороны не режет другую. `AppliesOnDate` дополнительно требует тот же день недели.

Карточка с другой недели или другой чётностью остаётся на доске и помечается `IsDimmed`. В «Ближайшую» такая пара не попадает.

## Доска

Колонки только пн–сб, заголовки из `AcademicCalendar.DayName`. Колонка сегодняшнего дня имеет `IsToday`. Воскресной колонки нет. Пара, созданная в воскресенье, записывается на понедельник — см. [interaction.md](interaction.md).

Поиск обрезается по краям. Пустой запрос показывает все пары группы. Иначе остаются пары, у которых предмет или преподаватель содержит запрос без учёта регистра. Аудитория и тип в поиск не входят.

Если после фильтра пар нет, `NextLessonLabel` получает `ScheduleComposer.EmptyScheduleText`: «Пар нет. Добавьте вручную или выберите группу из импортированного файла.» Колонки при этом пустые.

## Карточка

`LessonCardVm`:

| Поле | Откуда |
| --- | --- |
| `TimeText` | `чч:мм–чч:мм` |
| `Subject` | предмет |
| `Place` | аудитория, иначе «Онлайн» при непустом `MeetingUrl`, иначе «—» |
| `Meta` | тип, преподаватель, чётность (если не все недели), диапазон недель |
| `Badge` | «онлайн», если `MeetingUrl` — ссылка звонка |
| `IsOnline` | есть `MeetingUrl` или `LmsUrl` |
| `Accent` | практика `#34D399`, лабораторная `#FB923C`, звонок `#A78BFA`, остальное `#60A5FA` |

Подписи типов: Лекция, Практика, Лабораторная. Пустой тип в метаданные не пишется. Диапазон недель: `с–по нед.`; пустая граница заменяется на 1 или на `WeekFrom`.

## Ближайшая пара

`BuildNextLessonText` смотрит семь календарных дней от сегодня, воскресенье пропускает. Берётся первая пара, у которой `AppliesOnDate`, и для сегодняшнего дня начало ещё впереди. Завтра и дальше время начала не сравнивается с текущими часами.

Текст: `Ближайшая: предмет · сегодня|завтра|<день> чч:мм–чч:мм · место`. Если за неделю ничего нет — `Ближайших пар на неделю нет`.

Поиск фильтрует и эту строку: в кандидаты попадают только видимые пары.
