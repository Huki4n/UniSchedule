# Расписание

Доску собирает `ViewModels/ScheduleComposer`. Номер недели и чётность считает `Services/AcademicCalendar`. «Ближайшая» и подсветка сегодняшнего дня берут `DateTime.Now`. Колонки берут просматриваемую дату из `MainWindow.ReloadSchedule`.

## Неделя семестра

`GetWeekNumber(date, semesterStart)`: разница дат в днях. Если дата раньше начала семестра, номер равен 1. Иначе `дни / 7 + 1`. Неделя 1 нечётная (`WeekParity.Odd = 1`), чётные номера — `Even = 2`, «все недели» — `All = 0`.

Подпись шапки: `Неделя N · нечётная|чётная`.

`AppliesThisWeek`: неделя внутри `[WeekFrom, WeekTo]`, если границы заданы, и совпадает чётность. Открытая граница с одной стороны не режет другую. `AppliesOnDate` дополнительно требует тот же день недели.

Карточка, которая не действует в дату своей колонки, остаётся на доске и помечается `IsDimmed`. В «Ближайшую» такая пара не попадает.

## Доска

Колонки только пн–сб выбранной календарной недели. Понедельник недели считает `AcademicCalendar.StartOfWeek`. Заголовок колонки — `ColumnTitle`: «Понедельник, 5 окт.». `IsToday` — дата колонки совпадает с сегодня, а не только день недели. Воскресной колонки нет. Пара, созданная в воскресенье, записывается на понедельник — см. [interaction.md](interaction.md).

`ScheduleComposer.Build` принимает просматриваемую дату отдельно от «сейчас». Если её нет, берётся «сейчас». Подпись «Неделя N» считается от просматриваемой даты. `IsDimmed` смотрит на дату колонки: календарная неделя может задеть две недели семестра, и понедельник с пятницей тогда приглушаются по-разному. Строка «Ближайшая» всегда считается от «сейчас», листание недели её не меняет.

Поиск обрезается по краям. Пустой запрос показывает все пары группы. Иначе остаются пары, у которых предмет или преподаватель содержит запрос без учёта регистра. Аудитория и тип в поиск не входят.

Если после фильтра пар нет, `NextLessonLabel` получает `ScheduleComposer.EmptyScheduleText`: «Пар нет. Добавьте вручную или выберите группу из импортированного файла.» Колонки при этом пустые.

## Карточка

`LessonCardVm`:

| Поле | Откуда |
| --- | --- |
| `TimeText` | `чч:мм–чч:мм` |
| `Subject` | предмет |
| `Place` | аудитория, иначе «Онлайн» при непустом `MeetingUrl`, иначе «—» |
| `Meta` | тип, преподаватель, чётность (если не все недели), диапазон недель |
| `Badge` | «онлайн», если `MeetingUrl` — ссылка звонка и место уже не «Онлайн». При пустой аудитории место само пишется «Онлайн», второй строки нет |
| `IsOnline` | есть `MeetingUrl` или `LmsUrl` |
| `Accent` | `LessonAccent.For`: практика `#34D399`, лабораторная `#FB923C`, зачет `#FBBF24`, экзамен `#F87171`. Для остальных типов ссылка звонка даёт `#A78BFA`, иначе `#60A5FA` |
| `HomeworkLinks` | строки «ДЗ» на дату колонки. См. [homework.md](homework.md) |

Подписи типов: Лекция, Практика, Лабораторная, Зачет, Экзамен. Пустой тип в метаданные не пишется. Диапазон недель: `с–по нед.`; пустая граница заменяется на 1 или на `WeekFrom`. Непустые `MeetingUrl` и `LmsUrl` показываются на карточке отдельными строками. Одинаковый адрес без учёта регистра показывается один раз. Клик по строке открывает этот адрес и не открывает пару.

## Ближайшая пара

`BuildNextLessonText` смотрит семь календарных дней от сегодня, воскресенье пропускает. Берётся первая пара, у которой `AppliesOnDate`, и для сегодняшнего дня начало ещё впереди. Завтра и дальше время начала не сравнивается с текущими часами.

Текст: `Ближайшая: предмет · сегодня|завтра|<день> чч:мм–чч:мм · место`. Если за неделю ничего нет — `Ближайших пар на неделю нет`.

Поиск фильтрует и эту строку: в кандидаты попадают только видимые пары.

Сетка месяца — в [homework.md](homework.md).

## Одно название

Пары одной группы с одинаковым предметом, без учёта регистра, считает связанными `LessonSeries`. День и время у каждой свои. При сохранении существующей пары, если такие есть, после кнопки «Сохранить» спрашивается область: только эта, эта и следующие, все с этим названием. Отмена вопроса не закрывает панель пары. «Следующие» — более поздний день недели, а в тот же день более позднее начало. На выбранные пары копируются предмет, тип, преподаватель, кабинет, обе ссылки, заметки, чётность и диапазон недель. День, начало, конец и `Source` не копируются. Список соседей для области берётся из `GetLessons` в момент сохранения, а не из снимка при открытии панели: пара, удалённая с доски пока панель была открыта, в серию не входит. Эта пара и выбранные соседи пишутся одним `UpsertLessons`: одна транзакция SQLite.

Если название изменилось, первое название этого календарного дня пишется в `SubjectRollback`. Повторная смена в тот же день его не затирает. Кнопка у поля «Предмет» подставляет его обратно. Сохранение этого названия удаляет запись. На следующий день записи нет: чужие даты стираются при чтении и при новой записи. Удаление пары и повторный импорт уносят запись вместе с парой. Запомнить, забыть или ничего не делать решает `SubjectRollbackPolicy` по предыдущему названию, уже записанному на сегодня и новому. Окно только вызывает методы базы.
