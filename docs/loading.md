# Подгрузка

Доска читает пары выбранной группы из SQLite. Импорт заменяет ранее импортированные строки и не трогает пары, добавленные вручную.

## Чтение доски

`MainWindow.ReloadSchedule` вызывает `AppDatabase.GetLessons(SelectedGroup)` и `ScheduleComposer.Build` с текстом поиска, `DateTime.Now` и `SemesterStart`. Один и тот же `DateTime.Now` идёт и в доску, и в строку «Ближайшая».

`ReloadGroups` читает `GetGroups` (`DISTINCT GroupCode`). Если выбранной группы в списке нет, она вставляется первой. `ReloadAll` заново читает настройки и вызывает оба метода. После смены группы, импорта, сохранения пары и настроек доска пересобирается целиком: коллекция дней очищается и заполняется заново.

Порядок строк: `DayOfWeek`, затем `Start`.

## Импорт из окна

Кнопка импорта открывает `OpenFileDialog` (`*.xlsx`, каталог «Загрузки»). Тесты подставляют путь через `MainWindow.ImportFileOverride`.

`ItisExcelParser.Parse` → `AppDatabase.ReplaceImported` → диалог `ImportResult.FormatStoredMessage`. Если выбранной группы в файле нет, текст сообщает, что она останется пустой. Ошибка разбора показывается как «Импорт не удался» и базу не меняет: замена идёт одной транзакцией.

Выбранная группа при импорте не переключается.

## Импорт без окна

`App.TryHeadlessImport` срабатывает, если в аргументах есть `--import` и путь следом. Отчёт:

```text
OK groups=<число кодов групп с листа Расписание> lessons=<сколько записано> links=<сколько пар получили ссылку звонка>
group=<SelectedGroup>
<код группы>
...
```

Ошибка — строка `ERROR` и текст исключения. Процесс после этого завершается, окно не создаётся. `--data` в тех же аргументах выбирает файл базы. Настройки после импорта перечитываются и записываются обратно, группа из файла не подставляется.

`make import FILE=... OUT=...` вызывает уже собранный Release-exe.

## Лист «Расписание»

`ItisExcelParser`. Книга ClosedXML. Лист, в имени которого есть «Расписание»; если такого нет — первый лист. Объединённые ячейки читаются с левого верхнего угла диапазона.

| Место | Содержимое |
| --- | --- |
| Строка 2, колонки с 3 | Код группы. Пробелы схлопываются. |
| Колонка 1, с строки 3 | День. Пока день не распознан, строки пропускаются. День держится, пока не встретится следующий. |
| Колонка 2 | Время `ЧЧ:ММ–ЧЧ:ММ` (разделители `.` или `:`, тире `-`, `–`, `—`). Без времени строка пропускается. |
| Колонка группы | Текст пары. Пустая ячейка пропускается. |

День распознаёт `LessonTextParser.ParseDay`: понедельник … суббота. Воскресенья в файле нет.

Внутри одной группы дубликат отбрасывается по ключу `день|начало|конец|предмет|преподаватель` без регистра и без знаков препинания.

## Текст ячейки

`LessonTextParser.Parse` / `ParseAll`. Результат — `Lesson` с `Source = imported` и исходным текстом в `RawText`.

| Что ищется | Куда попадает |
| --- | --- |
| `нечетн. нед` / `четн. нед` | `Parity` = `Odd` / `Even`, иначе `All` |
| `N-M нед`, `с N недел`, одиночное `N нед` (1…20) | `WeekFrom` / `WeekTo` |
| `лек`, `прак`, `лаб` | `lecture` / `practice` / `lab` |
| `Фамилия И.О.` | `Teacher` |
| `ауд.`, `в 1301`, `КЗВК`, `УНИКС`, `Сим. центр`, голые 3–4 цифры вне слова «нед» | `Room` |
| URL звонка или `edu.kpfu` | `MeetingUrl` или `LmsUrl` |
| Своё время внутри текста, отличное от колонки | перезаписывает `Start` / `End` |
| «не будет», «перенос», даты `д.мм` | `Notes` |

Предмет — текст до двоеточия, до преподавателя или до запятой, обрезанный от слов типа занятия. «Дисциплины по выбору» режутся на несколько пар, если в ячейке больше одного преподавателя; иначе ячейка остаётся одной парой.

`MeetingLinks.ApplyOnlineNote` ставит заметку «онлайн», если `MeetingUrl` — ссылка звонка.

Хосты звонка: `telemost`, `mts-link`, `mtslink`, `meet.google`, `ktalk`, `teleboss`, `zoom.`, `t.me/`, `clck.ru`. LMS — URL, содержащий `edu.kpfu`.

## Лист «Ссылки»

Ищется по подстроке «Ссылки». Колонки со 2-й строки: дисциплина, преподаватель, группы, ссылка на занятие, ссылка LMS. Строка с дисциплиной «Дисциплина» и строки без предмета или групп пропускаются.

Ссылка прикрепляется к паре той же группы, если счёт предмета не ниже 2. Совпадение предмета: равенство 6, вхождение 5, два общих слова длиннее 3 символов — 3, одно такое слово — 2. Совпадение преподавателя добавляет 3. Уже заполненные URL пары не заменяются. `LinkMatches` считает пары, у которых `MeetingUrl` распознан как звонок.

Группы в ячейке через запятую. «курс(ы) по выбору» вырезается. Диапазон вида `11-321-11-325` подходит группе с тем же префиксом и номером внутри границ.

## Замена в базе

`ReplaceImported` в одной транзакции удаляет `Source='imported'` по всей базе и вставляет переданные пары с `Source='imported'`. Строки `manual` остаются. Повторный импорт поэтому стирает импорт всех групп, не только тех, что есть в новом файле.
