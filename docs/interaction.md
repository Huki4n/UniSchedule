# Взаимодействие

Главное окно — `MainWindow`. Диалоги — `Windows/LessonEditWindow`, `Windows/SettingsWindow`, `Windows/AppDialog`. Правила полей живут в `Services/LessonForm` и `Services/SettingsForm`. Code-behind читает контролы и вызывает эти правила.

Имена элементов ниже — контракт UI и сквозных тестов. Переименование ломает привязки и `AutomationId`.

## Главное окно

| Элемент | Имя | Что делает |
| --- | --- | --- |
| Группа | `GroupBox` | Редактируемый список групп из базы. Текущая группа всегда есть в списке, даже если пар у неё нет. |
| Поиск | `LessonSearchBox` | Фильтрует карточки и строку «Ближайшая». См. [schedule.md](schedule.md). |
| Неделя | `WeekLabel` | Подпись из `AcademicCalendar.WeekLabel`. |
| Ближайшая | `NextLessonLabel` | Текст ближайшей пары или пустого расписания. |
| Дни | `DaysHost` | Колонки пн–сб, источник — `ObservableCollection<DayColumnVm>`. |

Смена выбранной группы пишет `SelectedGroup`, обновляет `NotificationService` и пересобирает доску. Ввод в поле группы фильтрует выпадающий список по подстроке, не меняя сохранённую группу, пока пункт не выбран. При открытии списка, если текст совпадает с выбранным пунктом, показывается полный список.

Кнопки: импорт Excel, новая пара, настройки. Импорт описан в [loading.md](loading.md).

## Карточка

Клик открывает редактирование. Контекстное меню:

- «Изменить» — то же окно.
- «Удалить» — подтверждение `AppDialog.Confirm`, затем `DeleteLesson`.
- «Открыть ссылку» — `Process.Start` на `Lesson.PrimaryUrl` (сначала `MeetingUrl`, иначе `LmsUrl`). Если ссылки нет, диалог «Нет ссылки».

## Пара

`LessonEditWindow`. Новая пара: `Source = manual`, группа — выбранная, день — сегодняшний. Воскресенье подменяется на понедельник до открытия окна. Кнопка удаления у новой пары скрыта.

`LessonForm.TryValidate`:

- пустой предмет — «Укажите название предмета.»;
- время не `ЧЧ:ММ` или конец не позже начала — «Время укажите в формате ЧЧ:ММ, конец позже начала.»

Сохранение пишет день, время, предмет, тип (`lecture` / `practice` / `lab` или пусто), преподавателя, аудиторию, ссылки, чётность, недели и заметки. Пустые номера недель становятся `null`. У новой пары `Source` снова выставляется в `manual`. Существующая пара сохраняет свой `Source`, в том числе `imported`.

Удаление из окна редактирования ставит `Deleted` и по закрытии вызывает `DeleteLesson`.

## Настройки

`SettingsWindow` работает с копией `AppSettings`. Сохранение идёт только при `DialogResult = true`.

`SettingsForm`:

- минуты напоминаний — целые числа `>= 0`, иначе «Минуты напоминаний должны быть целыми числами.» и окно не закрывается;
- пустая группа заменяется на `11-321`;
- пустая дата начала семестра заменяется на `2026-09-01`.

После сохранения главное окно пишет настройки, при базе профиля вызывает `AutostartService.Apply`, обновляет уведомления и пересобирает доску. Кнопка проверки тоста описана в [notifications.md](notifications.md). Галочка «Добавить группу» только кладёт код в список комбобокса; в базу группа попадает как `SelectedGroup`, пары сами не создаются.

## Трей

`TrayService`: иконка «Расписание», пункты «Открыть» и «Выход», двойной щелчок открывает окно.

Закрытие главного окна при `MinimizeToTray` и живом приложении отменяется, окно скрывается. Выход — только «Выход» в трее (`App.IsExiting`). Если «сворачивать в трей» выключено, закрытие окна завершает приложение.

## Диалоги

`AppDialog.Info` — одна кнопка OK. `AppDialog.Confirm` — OK и «Отмена». Оба возвращают `bool` через `ShowDialog`.

## Стили

Ключи `AppBg`, `AccentButton`, `LabelText`, `DialogScrollViewer` не переименовывать. Файлы: `Themes/Colors.xaml`, `Themes/Controls.xaml`, `Themes/Calendar.xaml`. Конвертеры остаются в `App.xaml`.
